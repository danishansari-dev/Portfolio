# Personal Portfolio — Danish Ansari

This project is a personal portfolio showcasing my work as an ML Engineer and Full-Stack Builder.

## Project info

Built with a focus on high-performance, modern web aesthetics and clean UI.

## Technologies Used

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Framer Motion

## Local Development

To run this project locally, follow these steps:

1. **Clone the repository**:
   ```sh
   git clone <YOUR_GIT_URL>
   ```

2. **Navigate to the project directory**:
   ```sh
   cd portfolio
   ```

3. **Install the necessary dependencies**:
   ```sh
   npm install
   ```

4. **Start the development server**:
   ```sh
   npm run dev
   ```

## Deployment

The project can be deployed to any static site hosting service like Vercel, Netlify, or GitHub Pages.

To build the production bundle:
```sh
npm run build
```
